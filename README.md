Aplikasi Daftar Nilai UTS

Panduan singkat untuk Bapak/Ibu Guru. Tidak perlu paham komputer. Cukup ikuti langkahnya satu per satu.

Aplikasi ini untuk apa? Mengisi Daftar Nilai Ujian Tengah Semester (UTS) siswa Kelas X dan Kelas XI, lalu mengunduhnya sebagai Excel, Word, atau PDF dengan bentuk yang sama seperti lembar nilai sekolah. Tidak perlu lagi mengetik ulang di Word atau Excel untuk setiap siswa.

1. Sebelum mulai
Gunakan Google Chrome atau Microsoft Edge di laptop/komputer. Di HP juga bisa, tetapi layar laptop lebih nyaman.
Alamat web: https://rehzaherza.github.io/Aplikasi-Daftar-Nilai-UTS/
Data yang Bapak/Ibu isi tersimpan otomatis di laptop/HP yang sedang dipakai, bukan di internet. Karena itu:
Selalu pakai laptop/HP dan peramban yang sama sampai selesai.
Jangan menghapus "data penjelajahan" atau "cookies" di Chrome.
Buat cadangan (lihat bagian 8).
2. Mengenal tampilan

Layar terbagi dua:

Bagian	Isinya
Kiri (menu)	Tambah siswa, daftar siswa, tombol Unduh, Cadangan data, Pengaturan lembar
Kanan (lembar nilai)	Tampilan lembar nilai. Kotak kuning bisa diisi

Di atas lembar ada tiga tab:

Lembar Siswa: mengisi nilai satu siswa sekaligus (semua mapel).
Input per Mapel: mengisi nilai satu mapel sekaligus untuk semua siswa.
Rekap Kelas: satu tabel berisi semua siswa dalam satu kelas.
3. Langkah pertama: cek Pengaturan lembar

Klik Pengaturan lembar di menu kiri. Cek dan ubah bila perlu:

Semester (misalnya GANJIL)
Tahun pelajaran (misalnya 2026/2027)
Tempat dan tanggal (misalnya Manggar, Oktober 2026)
Nama sekolah
Nama dan NIP kepala sekolah
Nama dan NIP wali kelas

Isian ini akan muncul di bagian atas dan tanda tangan lembar nilai. Cukup diisi sekali.

4. Memasukkan data siswa

Ada tiga cara. Pilih yang paling mudah.

Sebelum menambah siswa, pilih dulu Kelas X atau Kelas XI di menu kiri, lalu ketik nama kelas pada kotak di sebelahnya, misalnya X RPL.

Cara A: satu per satu

Klik + Tambah siswa, lalu ketik nama dan kelas di lembar.

Cara B: tempel banyak nama sekaligus
Siapkan daftar nama di Excel atau Word, satu nama per baris.
Salin (Ctrl + C) semua nama itu.
Di aplikasi, buka Tempel banyak nama, tempel (Ctrl + V), lalu klik Tambahkan semua.
Cara C: impor dari file Excel atau CSV
Buka Impor dari Excel / CSV, lalu klik Pilih berkas.
Pilih file Excel (.xlsx) atau CSV yang berisi daftar nama.
Aplikasi menampilkan pratinjau. Klik Tambahkan kalau sudah benar.

Tips untuk file impor:

Beri judul Nama pada kolom nama. Kolom Kelas boleh ada, boleh tidak.
Nama yang sudah ada tidak akan masuk dua kali.
File Excel lama berakhiran .xls: buka di Excel, lalu Simpan Sebagai .xlsx.
Salah masuk? Menghapus siswa

Klik tanda ✕ di samping nama.

Siswa yang masih kosong langsung terhapus.
Siswa yang sudah ada nilainya: klik ✕ sekali, tombol berubah jadi Hapus?, lalu klik sekali lagi untuk memastikan.
Hapus semua siswa yang kosong membersihkan sekaligus baris yang belum ada nama dan nilainya.
5. Mengisi KKTP

KKTP adalah batas nilai tuntas tiap mata pelajaran. Setiap mapel punya KKTP sendiri.

Isi di kolom KKTP pada lembar, atau di tab Input per Mapel (ada juga panel Atur KKTP semua mapel untuk mengisi semuanya sekaligus).
Cukup diisi sekali. KKTP otomatis berlaku untuk semua siswa pada tingkat yang sama (Kelas X atau Kelas XI).

Dengan KKTP terisi, kolom Ket akan terisi sendiri:

TUNTAS: nilai sama dengan atau di atas KKTP
TIDAK TUNTAS: nilai di bawah KKTP

Bapak/Ibu tidak perlu mengetik apa pun di kolom Ket.

6. Mengisi nilai

Ada dua cara. Pilih yang lebih enak.

Cara 1: per siswa (tab Lembar Siswa)
Klik nama siswa di daftar kiri.
Klik kotak NILAI UTS mapel pertama, ketik nilainya, lalu tekan Enter. Kursor pindah ke mapel berikutnya.
Setelah mapel terakhir, Enter sekali lagi membuka siswa baru.
Cara 2: per mata pelajaran (tab Input per Mapel)

Cocok kalau Bapak/Ibu memegang satu mapel dan punya nilai satu kelas.

Pilih tingkat dan kelas.
Pilih mata pelajaran (atau pakai tombol ‹ Mapel dan Mapel ›).
Isi KKTP mapel itu.
Ketik nilai siswa dari atas ke bawah. Enter pindah ke siswa berikutnya.

Dua cara ini memakai data yang sama. Hasilnya otomatis muncul di keduanya.

Kalau ada kotak berwarna merah muda/merah

Artinya isian itu bukan angka atau di luar 0 sampai 100. Perbaiki sebelum diunduh.

7. Mengunduh hasil

Di menu kiri bagian Unduh, pilih dulu cakupannya:

Pilihan	Hasilnya
Semua siswa	Satu file berisi semua siswa (Excel: satu sheet per siswa; Word dan PDF: satu halaman per siswa)
Siswa terpilih saja	Hanya siswa yang sedang dibuka
Satu file per siswa (ZIP)	Satu file ZIP berisi file terpisah per siswa, misalnya DAFTAR NILAI UTS - AHMAD FAUZI.pdf

Lalu klik tombol Excel, Word, atau PDF. File akan tersimpan di folder Downloads.

Catatan:

Pilihan ZIP cocok kalau lembar nilai mau dikirim ke masing-masing siswa/orang tua. Untuk membukanya, klik kanan file ZIP lalu Extract All.
Pilihan Semua siswa cocok untuk dicetak sekaligus.
Siswa yang belum diisi sama sekali tidak ikut diunduh.
Rekap satu kelas

Buka tab Rekap Kelas, pilih tingkat dan kelas, lalu unduh Excel/Word/PDF. Hasilnya satu tabel berisi semua siswa dan semua mapel, lengkap dengan jumlah, rata-rata, dan keterangan tuntas. Nilai di bawah KKTP berwarna merah. Cetaknya mendatar (landscape).

8. Cadangan data (penting!)

Karena data tersimpan di peramban, buat cadangan secara berkala, terutama setelah selesai mengisi banyak nilai.

Cadangkan: menyimpan semua data ke satu file .json. Simpan file itu di tempat aman (flashdisk atau Google Drive).
Pulihkan: memasukkan kembali data dari file cadangan. Berguna kalau ganti laptop atau datanya hilang. Setelah memilih file, klik Ganti data untuk memastikan.
9. Masalah yang sering terjadi

Data saya hilang. Biasanya karena data penjelajahan Chrome dihapus, atau Bapak/Ibu membuka dari laptop/peramban lain. Pulihkan dari file cadangan. Kalau belum pernah membuat cadangan, data tidak bisa dikembalikan, jadi biasakan membuat cadangan.

Tombol Excel/Word/PDF tidak mengunduh. Pastikan memakai Chrome atau Edge terbaru, dan Chrome tidak memblokir unduhan. Perhatikan tulisan status kecil di bawah tombol Unduh.

Tab "Input per Mapel" tidak ada. Berarti aplikasi yang terbuka masih versi lama. Hubungi pengelola web untuk memperbarui.

Dua siswa namanya sama. Bisa. Di file ZIP, nama file otomatis diberi nomor, misalnya AHMAD (2).

Kolom Ket kosong. Isi dulu KKTP dan nilai untuk mapel itu. Keduanya harus terisi.

Salah memilih Kelas X / Kelas XI. Di atas lembar ada pilihan Template. Ganti ke tingkat yang benar. Daftar mata pelajaran akan menyesuaikan.

10. Ringkasan alur kerja
Buka web, cek Pengaturan lembar.
Tambahkan siswa (tempel banyak nama atau impor Excel).
Isi KKTP tiap mapel.
Isi nilai (per siswa atau per mapel).
Periksa kotak merah.
Unduh hasilnya.
Cadangkan datanya.

Selamat menggunakan!
